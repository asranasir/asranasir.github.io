Personal academic portfolio site built with Jekyll. All content lives in `_data/profile.yml` — update one YAML file to change everything on the page.

## Run Locally

```bash
jekyll serve --host 0.0.0.0 --port 4000
```

Site at `http://localhost:4000`.

## Update Content

Edit `_data/profile.yml`. Sections are data-driven — no HTML changes needed for adding publications, experience, projects, certifications, or references.
